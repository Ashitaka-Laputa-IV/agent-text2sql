# db 目录说明

本目录存放项目使用的示例数据库 `AdventureWorksLT.db`。

## AdventureWorksLT.db

Microsoft 提供的示例数据库, 体积较大, 已在仓库根目录 `.gitignore` 中忽略 (`db/AdventureWorksLT.db`), 不纳入版本控制。

### 下载

运行 `download_db.py` 即可自动把数据库下载到本目录:

```bash
python download_db.py
```

下载来源: <https://github.com/Ashitaka-Laputa-IV/adeventure_works_db/blob/main/AdventureWorksLT.db>
